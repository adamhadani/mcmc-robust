# Tail-direction maps for NUTS: findings

> **Exploration snapshot, branch `explore/tail-direction-transforms`, not maintained docs.** Every number is copied
> from a committed file in `explore/tail_direction/results/` (named next to each table). Full per-arm tables:
> `results/tables.md` (main) and `results/tables_heldout.md` (held-out), generated by `summarise.py`.

## 1. What was run

**Maps** (`maps.py`). Each map is block-diagonal and is written as the inverse map x = ψ(z) with an exact log-determinant.
- `affine`: x = μ + L z.
- `radial`: x = μ + L·R·sinhc(‖z‖)·z, where sinhc(s) = sinh(s)/s. Its log-det is
  log det L + k log R + (k−1) log sinhc(s) + log cosh(s).
  sinhc, log sinhc and log cosh are evaluated as functions of s², using a Taylor branch for s² < 1e-3, so values
  and gradients are finite at z = 0.
- `coord`: the production per-coordinate arcsinh.
- `lincoord`: x = μ + A·(R ⊙ sinh z). Used only as the oracle tail frame for one held-out target.

L comes from a coordinate median plus a regularised Tyler shape: robustly standardise, shrink towards I with
ρ = k/n, then rescale so the median squared Mahalanobis radius equals the χ²ₖ median.

**Verification** (`check_maps.py`, `results/check_maps.json`). All checks pass at these worst errors:
- Scalar helpers vs 50-digit `Decimal`, on both sides of the Taylor switch: 1.5e-13 (relative).
- Inverse round trip: 3.3e-15.
- Log-det vs `slogdet(jacfwd(inverse))`: 1.4e-15 (relative).
- Hand-derived pullback gradient vs `jax.grad`: 5.6e-13.
- These cover radius s ∈ {0 exactly, 1e-12, …, 0.0315 and 0.0317 (either side of the switch), …, 100, 300}, a
  composite map with all four block kinds, and a d = 20 radial map.
- The coord block matches the production `JaxArcsinhTransform` to 4.5e-16.

**Pipeline** (`pipeline.py`). It mirrors `sample_blackjax_unified_nuts`:
- same key splits and 0.5·N(0, I) initial positions;
- same Phase 1 (75 window-adaptation steps on the R = 3 arcsinh map), using the second half pooled across chains,
  152 draws in all;
- then 425 window-adaptation steps and 1,000 draws in the new z-space;
- 4 chains, max 10 doublings.

Gradients are counted per phase (one per chain at init, plus leapfrog steps), and Phase 1 is charged to every arm
that uses it. The Phase 1 draws reproduce the production calibration exactly in 140/140 main and 60/60 held-out
records.

**Arms.**

| Arm | What it does |
|---|---|
| `stock` | BlackJAX NUTS, diagonal metric |
| `stock_dense` | BlackJAX NUTS, dense metric; the baseline for whitening |
| `coord` | `sample_blackjax_unified_nuts` (production coordinate arcsinh) |
| `whiten` | global Tyler affine map; an ablation |
| `radial` | global whitening + radial arcsinh, R = 0.5 |
| `composite` | block map from the **oracle** partition: tail-dependent block → radial; independent heavy coordinate → coord; light → affine |
| `selected` | the same block map, but with the partition from the **Phase 1 diagnostic** |

Identical maps are run once (Table 1 marks these as "= arm").

**Diagnostic.**
- Robustly standardise the Phase 1 draws.
- Cluster coordinates agglomeratively. Repeatedly merge the two clusters whose *cluster radii* co-exceed most often
  (exceedance level u = 0.8), while that co-exceedance rate is above τ = 0.4.
- Classify each cluster by the Hill index of its radius:
  - heavy if below 3.5 for a singleton, or below 6 for a block;
  - and if the Hill index of the full radius is above 6, everything is light.

**Calibration on pilot seeds** (the main seeds are 0–4):
- Diagnostic thresholds: chosen on 70 Phase-1 runs (seeds 100–109) by partition match.
  The winner had role accuracy 0.934 and an exact partition in 61% of runs (`results/pilot_tune.json`).
- Radial R: chosen on seeds 100–102 (`results/pilot_radial_R_summary.json`). On `rot_t2_d20`, the median
  tail-ESS/grad was:

  | R | 0.35 | 0.5 | 0.75 | 1.5 | 3 | √k |
  |---|---|---|---|---|---|---|
  | tail-ESS/grad | 0.0448 | 0.0433 | 0.0377 | 0.0306 | 0.0240 | 0.0184 |

  Smaller R hurts the radial map on the Gaussian. R = 0.5 was chosen.

**Targets** (`targets.py`). Location 0 throughout.

| Target | Description |
|---|---|
| `rot_t1_d10` | rotated multivariate t, ν = 1, d = 10, condition 25 |
| `rot_t2_d10` | same with ν = 2 (`rot_t2_d10` is `corr_t2` from the earlier ablation) |
| `rot_t1_d20` | rotated multivariate t, ν = 1, d = 20, condition 25 |
| `rot_t2_d20` | same with ν = 2 |
| `prod_t_d10` | axis-aligned product t, ν from 1 to 3, scales from 1 to 5 |
| `mixed_d15` | 5-d rotated multivariate t (ν = 1) block + 5 independent Cauchy + 5 independent Gaussian |
| `rot_gauss_d20` | rotated Gaussian, condition 100 |

Three held-out targets were added after the main run:
- `rot_t3_d10`: rotated multivariate t with ν = 3.
- `two_blocks_d12`: two rotated elliptical blocks (ν = 1 and ν = 2) plus 4 Gaussians.
- `rot_prod_cauchy_d10`: x = Q·diag(s)·u with u iid Cauchy. Each marginal is exactly Cauchy with scale
  Σⱼ |Qᵢⱼ| sⱼ, which was checked by simulation.

**Metrics** (via `evaluate_chains_with_arviz`):
- coordinate-mean tail-ESS per gradient;
- worst-coordinate tail-ESS;
- max split R-hat;
- post-warm-up divergences;
- tail-probability error |P̂(xᵢ < qₚ) − p| at the exact marginal quantiles for p ∈ {0.01, 0.99}, averaged over
  coordinates and p, with MCSE from the indicator's ESS.

## 3. Where each map wins and loses

**Radial (global whitening + radial arcsinh).**
- Wins: every elliptical target, including ν = 3, on every seed. Its tail-probability error is the lowest and stays
  within one MCSE.
- Loses:
  - tails that are independent across coordinates: product t (0.39×), the mixed target (0.44×, with divergences);
  - rotated-product tails: it is biased there;
  - light targets: on the Gaussian it reaches 0.44 of whitening alone.
- Why: the map couples coordinates through ‖x‖. When one coordinate is extreme and the others are not, the pullback
  becomes funnel-like.

**Coordinate arcsinh (production).**
- Wins: axis-aligned product tails.
- Moderate on elliptical tails (1.4–3.9× vs stock), as the earlier ablation found.
- Costs 0.82× on the rotated Gaussian.
- Biased on rotated-product tails. The tails then lie along diagonal ridges in z-space whose width shrinks
  exponentially, so NUTS can't enter them, and R-hat doesn't flag it.

**Composite (block map).**
- Best or tied-best wherever its partition is correct: 2.24× on mixed and 6.08× on two blocks against coord;
  equal to radial, coord or whiten on the pure targets.

**Why the composite is block-wise, not sequential** (`results/sequential_composite_check.json`).
- Applying whitening → radial → coordinate arcsinh to *every* coordinate over-transforms the tails. On an isotropic
  ν = 1 t, the second derivative of log π along an axis is −9.92, −27.28 and −74.20 at t = 3, 4 and 5. The
  prediction −ν·sinh(t) gives −10.02, −27.29 and −74.20.
- So the tails become doubly exponential (stiff), whereas the single maps stay at the β = 1 boundary.

**Whitening.**
- Alone it is just a dense metric. It matches `stock_dense` on the Gaussian and doesn't fix heavy tails.
- The radial nonlinearity is what carries the gain.

## 4. Diagnostic accuracy

**Main run** (35 target-seeds, `summary.json` → `diagnostic.aggregate`):
- its label matched the empirically best map in 27/35, and the oracle label in 27/35;
- partition exact in 22/35; mean role accuracy 0.96;
- selected ÷ best: median 1.00, worst 0.57, ≥ 0.9 in 28/35.

The failure modes were:
1. Splitting one coordinate off an elliptical block: 0.57–0.66 of the best (`rot_t2_d10` seed 4; `rot_t2_d20`
   seeds 3 and 4).
2. Labelling product-t coordinates with ν ≈ 2.5–3 "light": 0.84–1.02 of the best.
3. False two-coordinate blocks on the mixed target. A Cauchy+Gaussian radial block caused 59 divergences on seed 4;
   seed 1 reached 0.60 of the best.

**Held-out run** (15 target-seeds):
- best label in 6/15; within 10% of the best in 7/15; median 0.77; worst 0.04.
- On `rot_t3_d10`, ν = 3 tails were classified light or fragmented in 4/5 seeds (0.26–0.56 of the best). A Hill
  index from 152 draws can't separate ν ≈ 3 from Gaussian tails.
- On `rot_prod_cauchy_d10`, the diagnostic can't propose the right frame: extremes co-occur, so it says "radial".
- On `two_blocks_d12` it worked (0.92–1.00 of the best).

The task's suggested "Hill index of the radius vs the marginals" test can't separate elliptical from product tails:
in both cases the radius index equals the smallest marginal index. It is useful only as a global heavy/light gate,
which is how it is used here.

## 5. Novelty check (short: about 10 searches, abstracts and HTML read)

**Known pieces.**
- Regularised Tyler M-estimation (Chen, Wiesel & Hero 2011; Pascal et al. 2014).
- Affine + radial maps for heavy tails:
  - Johnson & Geyer 2012, for random-walk Metropolis.
  - Stereographic MCMC (Yang, Łatuszyński & Roberts 2024).
  - **Adaptive stereographic MCMC** (Bell, Łatuszyński & Roberts, arXiv:2408.11780). It adapts γ = (μ, Σ) with the
    empirical mean and Σ = d × empirical covariance over the latest quarter of epochs, rescaled by a constant for
    t targets, on an adapt-increasingly-rarely schedule. It has no robust estimator, no per-coordinate component,
    no blocks and no diagnostic. Its kernels are random walk, slice and bouncy particle; the authors report that
    stereographic HMC attempts "fall off the sphere".
  - **Brešar & Mijatović 2026** (arXiv:2608.04284). A radial contraction μ + R·RC_β(𝒯_ω(z/R)) whose (μ, R, Möbius ω)
    are tuned by variational inference. It treats tails radially only and states that its "strict symmetry implicitly
    assumes that the probability mass is nearly isotropic".
- Grouping coordinates by co-occurring extremes: Fomichov & Ivanovs, *Biometrika* 2023 (spherical k-means /
  k-principal-components clustering).
- Direction- and coordinate-dependent tails in variational inference and flows: ATAF (Liang et al., ICML 2022),
  COMET flows (IJCAI 2022), Hickling & Prangle (ICML 2025).

**Not found.** A tail-dependence diagnostic run during NUTS warm-up that partitions coordinates into
whitened-radial blocks, per-coordinate arcsinh coordinates and affine light coordinates, with an exact pullback.

**Verdict.**
- The block-structured, diagnostic-partitioned pullback looks new *as a combination*.
- Whitened radial arcsinh + NUTS on its own is a small step from Johnson & Geyer plus adaptive stereographic MCMC,
  and should not be claimed as new.

## 6. Recommendation: **iterate**

**Why not drop it.** The radial block gives large, seed-stable gains on elliptical tails (3.2–9.5× over production
on 25/25 target-seeds). The block composite wins on mixed structure (2.2× and 6.1×).

**Why not productionise yet.**
- The diagnostic is the weak link (6/15 on held-out targets).
- R and the thresholds were tuned on the same target families.
- The rotated-product target shows that coordinate and radial maps can be silently biased. This also applies to the
  production coordinate arcsinh.

**Next steps.**
1. Give Phase 1 more draws, or a more permissive heavy/light rule for tail-dependent blocks (radial on ν = 3 was
   2.2× better than whitening).
2. Re-test singletons against large blocks, and forbid blocks that mix heavy and light coordinates.
3. Estimate the tail frame with ICA-style unmixing, and distinguish elliptical from rotated-product extremes
   (angular concentration of extreme whitened draws). The oracle frame gives 15× and removes the bias.
4. Add a check that flags tails the chain never visits (MCSE can't).
5. Test on posteriordb heavy-tailed posteriors, with nutpie flow adaptation and the diffeomorphic contraction
   sampler as baselines.

## 7. Caveats

- `stock` here is my vmapped pipeline. It differs from `run_blackjax_sampler` in its initial positions. My target
  densities differ from the repo classes at the 1e-15 level, so the per-seed numbers are independent replicates of
  the earlier ablation, not reproductions.
- Gradient counts exclude the O(d²) cost of whitening per gradient.
- Wall-clock time isn't compared (compile time dominates).
- Shrinkage ρ = k/n is a heuristic.

## 8. Independent check of the silent truncation (coordinating session)

This check was run on branch `feat/ablation-runner-docs` with its own script, not this branch's code:
- target x = Q·diag(s)·u, with u iid Cauchy, d = 10, Q from `default_rng(0)` and s = geomspace(1, 5);
- `sample_blackjax_unified_nuts`, 4 chains × 1,000 draws, seeds 0–2.

**Arcsinh.** In every coordinate on every seed, the fraction of draws below the exact 1% quantile and above the
exact 99% quantile was 0.0000. Max R-hat was 1.02–1.04.

**Stock NUTS** (`transform_kind="identity"`) under-samples the tails but does visit them. The per-coordinate
medians were 0.0006–0.0030 below the 1% quantile and 0.0005–0.0119 above the 99% quantile.

The committed version of this check is planned for the ablation runner, as a rotated-product-Cauchy target.
